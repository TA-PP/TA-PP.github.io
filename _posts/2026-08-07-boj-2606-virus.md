## 문제 정의

컴퓨터들이 네트워크로 연결되어 있을 때,
1번 컴퓨터가 바이러스에 감염되면 연결된 컴퓨터 중 몇 대가 감염되는지 구하는 문제다.

## 접근 및 설계

그래프로 컴퓨터 간 연결 관계를 표현한 뒤,
1번 컴퓨터에서 DFS를 시작한다.

방문하지 않은 컴퓨터만 계속 탐색하면
1번 컴퓨터와 연결된 모든 컴퓨터를 찾을 수 있다.

## 알고리즘 풀이

1. 인접 리스트로 네트워크를 구성한다.
2. `visited` 배열을 만든다.
3. 1번 컴퓨터에서 DFS를 시작한다.
4. 방문한 컴퓨터 수에서 1번 컴퓨터를 제외한다.

## 최종 제출 코드

```python
def dfs(node):
    visited[node] = True

    for next_node in network[node]:
        if not visited[next_node]:
            dfs(next_node)

## 오늘의 회고

DFS는 종료 조건을 별도로 작성하지 않아도,
더 이상 방문할 수 있느 ㄴ노드가 없으면 자연스럽게 재귀 호출ㄹ이 끝난다는 점을 다시 확인했다.
